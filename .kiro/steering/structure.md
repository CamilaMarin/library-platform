## Module notes

- `search` and `import` live inside `library/` as use cases, not as separate modules (adr/0010, adr/0011).
- `reading_selection` has its own spec but lives within the Library bounded context at implementation level (adr/0013).
- Each context's `domain/` never imports FastAPI, SQLAlchemy, or any framework.
- Contexts share IDs (`user_id`, `book_id`) but not internal models.
