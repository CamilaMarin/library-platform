# API — EntreLíneas (Resource Map)

REST + JSON. OpenAPI auto-generated by FastAPI (the source of truth for the exact contract; this file is a high-level map).

## Authentication (custom JWT — see adr/0004)

- `POST /auth/register` — user registration (requires consent in the same flow)
- `POST /auth/consent` — explicit data-processing consent acceptance
- `POST /auth/login` — login, returns Access Token + Refresh Token
- `POST /auth/refresh` — rotates Refresh Token, issues new Access Token
- `POST /auth/logout` — revokes Refresh Token

## Users

- `GET /users/me` — own profile
- `PATCH /users/me` — update profile
- `DELETE /users/me` — account cancellation (triggers ARCO cancellation flow)
- `GET /users/me/export` — data portability (ARCO)

## Family Groups

- `POST /groups` — create family group
- `GET /groups/{id}` — group detail
- `POST /groups/{id}/invitations` — invite member
- `POST /groups/{id}/invitations/{id}/accept` — accept invitation

## Library (Books + Copies)

- `POST /books` — create book (intellectual work metadata)
- `GET /books?query=` — search books (metadata, external autocomplete)
- `GET /books/metadata/search?query=&type=` — search external metadata (Open Library) for book autocomplete; requires auth; type: isbn|text
- `PATCH /books/{id}` — edit metadata
- `DELETE /books/{id}` — delete book (409 if copies exist)
- `POST /copies` — create copy (physical or digital; digital requires separate encrypted upload)
- `GET /copies/{id}` — copy detail
- `PATCH /copies/{id}` — edit copy
- `DELETE /copies/{id}` — delete copy

## Integrated Reader (see adr/0014)

- `GET /copies/{id}` — copy detail (format, type, status — never exposes file_ref)
- `GET /copies/{id}/file` — serve encrypted file (owner only, streamed)
- `GET /copies/{id}/progress` — get reading progress (position, percentage, format)
- `PUT /copies/{id}/progress` — save reading progress (upsert, idempotent)

> **Deferred to v1 (reader-extras):** bookmarks and notes endpoints.

## Reading Selection (see adr/0013)

- `POST /groups/{id}/draws` — execute draw (filters + participants in body)
- `GET /groups/{id}/draws` — draw history

## Loans (physical copies only)

- `POST /copies/{id}/loans` — register loan
- `PATCH /loans/{id}/return` — register return

## Clubs (single family group only in MVP — see adr/0006)

- `POST /clubs` — create club (associated with a group)
- `GET /clubs/{id}` — club detail
- `PATCH /clubs/{id}/active-book` — set active book
- `POST /clubs/{id}/comments` — post comment
- `POST /clubs/{id}/reading-turns` — create reading turn
- `PATCH /reading-turns/{id}` — update turn

## Reviews (see adr/0007 for visibility model)

- `POST /reviews` — create review (with `visibility`: private | shared, `shared_with`: {type, id})
- `PATCH /reviews/{id}` — edit review
- `DELETE /reviews/{id}` — delete review
- `GET /books/{id}/reviews` — list reviews (filtered by access)

## Privacy & Audit

- `GET /privacy/processing-record` — processing record (internal/audit)

## Conventions

- All endpoints return errors in a consistent format (`{ "error": { "code", "message" } }`).
- No copies endpoint allows `GET` of a digital file for a `user_id` different from the owner — validated in the application layer, not just the UI.
- Endpoints touching personal data automatically log to the audit log (cross-cutting middleware).
- Access Token required in header `Authorization: Bearer <token>` for all authenticated endpoints.
