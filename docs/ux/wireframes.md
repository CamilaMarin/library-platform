# Wireframes — EntreLíneas

Pendiente de diseño visual. Este archivo describe la intención de layout de las pantallas clave del MVP en baja fidelidad, como punto de partida para wireframes reales (Figma, o generados como mockup interactivo).

## Home / Dashboard
- Header con nombre del grupo familiar activo.
- Tarjeta destacada: "🎲 ¿Qué leemos este mes?" con CTA a `/draw`.
- Club activo (si existe): libro, fecha de discusión, avatar de miembros.
- Lista corta: préstamos pendientes de devolución.

## Mi biblioteca
- Toggle Físico / Digital.
- Grid de portadas con estado (disponible / prestado).
- Botón flotante "Agregar libro".

## Detalle de club
- Portada + metadatos del libro activo.
- Hilo de comentarios con marcado de spoiler colapsado por defecto.
- Widget de turno de lectura (avatar de quién tiene el turno actual).

## Panel de privacidad
- Lista clara de los 4 derechos ARCO + portabilidad, cada uno como acción de un clic con confirmación.
- Historial de consentimientos aceptados con fecha y versión.

> Siguiente paso sugerido: generar un mockup interactivo de estas pantallas cuando se quiera validar el flujo visual antes de codificar.
