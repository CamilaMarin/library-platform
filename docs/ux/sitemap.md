# Sitemap — EntreLíneas (MVP)

- `/onboarding` — consentimiento de datos + creación de cuenta
- `/login`
- `/` — Home / Dashboard (resumen de grupo, club activo, sorteo del mes)
- `/library` — Mi biblioteca (lista de ejemplares propios)
- `/library/add` — Agregar libro (metadatos) + ejemplar (físico o digital)
- `/library/read/{copy_id}` — Lector integrado (EPUB/PDF, solo archivos propios)
- `/group` — Grupo familiar (miembros, invitaciones)
- `/draw` — Sorteo / selección conjunta de lectura
- `/clubs` — Lista de clubes (dentro del grupo familiar)
- `/clubs/{id}` — Detalle de club (libro activo, comentarios, turno de lectura)
- `/loans` — Préstamos activos y su estado
- `/profile` — Perfil, historial de lectura, reseñas
- `/privacy` — Panel ARCO (exportar, rectificar, cancelar, oponerse)
