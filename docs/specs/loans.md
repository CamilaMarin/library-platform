# Spec — Loans

## Requirement: Préstamos entre personas

**User Story:** Como lector, quiero registrar cuándo le presto un libro físico a alguien, para saber dónde está cada ejemplar de mi biblioteca.

### Acceptance Criteria
1. EL SISTEMA DEBERÁ permitir registrar préstamos únicamente sobre ejemplares tipo "físico".
2. CUANDO un ejemplar físico está prestado, EL SISTEMA DEBERÁ marcarlo "no disponible" y permitir una fecha de devolución estimada opcional.
3. EL SISTEMA NO DEBERÁ ofrecer transferencia o acceso temporal a un archivo digital entre cuentas distintas bajo ningún concepto de "préstamo".
